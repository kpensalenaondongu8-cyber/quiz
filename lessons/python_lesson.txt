----------------------------------------------------------------------
1. VARIABLES & NAMING RULES
----------------------------------------------------------------------
Variables are containers for storing data values. 
- Must start with a letter or an underscore (_).
- Cannot start with a number (e.g., 2myvar is INVALID).
- Can only contain alphanumeric characters and underscores (A-z, 0-9, _).
- Case-sensitive (age, Age, and AGE are three different variables).

Example:
    user_name = "Alice"
    user_age = 24

----------------------------------------------------------------------
2. CORE DATA TYPES
----------------------------------------------------------------------
Python automatically detects data types. The core types include:

- String (str): Text wrapped in quotes.
  Example: "Hello World" or 'Python'

- Integer (int): Whole numbers without decimals.
  Example: 10, -5, 0

- Float (float): Numbers containing decimal points.
  Example: 3.14, -0.5, 10.0

- Boolean (bool): Logical values representing truth states.
  Value: True or False (Note the capital letters!)

- NoneType (None): Represents the absence of a value or a null value.

You can check any variable's data type using the type() function:
  print(type(5))  # Output: <class 'int'>

----------------------------------------------------------------------
3. BUILT-IN DATA STRUCTURES (COLLECTIONS)
----------------------------------------------------------------------
- List: Ordered, mutable (changeable) collection. Allows duplicates.
  Syntax: unique_list = ["apple", "banana", 10, True]
  Add item: unique_list.append("orange")

- Tuple: Ordered, IMMUTABLE (cannot change after creation) collection.
  Syntax: structural_tuple = (1, 2, 3)

- Dictionary (dict): Unordered collection of Key-Value pairs. Mutable.
  Syntax: user_profile = {"name": "Alice", "score": 95}
  Access item: user_profile["name"]

- Set: Unordered collection of UNIQUE items. Duplicates are ignored.
  Syntax: unique_numbers = {1, 2, 3, 3} # Evaluates to {1, 2, 3}

----------------------------------------------------------------------
4. OPERATORS QUICK GUIDE
----------------------------------------------------------------------
- Arithmetic: + (Add), - (Sub), * (Mult), / (Div, returns a float)
- // (Floor Division): Divides and rounds down to the nearest integer.
  Example: 5 // 2 = 2
- % (Modulus): Returns the remainder of a division.
  Example: 5 % 2 = 1
- ** (Exponentiation): Power operator.
  Example: 2 ** 3 = 8
- Strict Equality: == (Checks if values match)
- Assignment: = (Assigns a value to a variable name)

----------------------------------------------------------------------
5. CONDITIONAL STATEMENTS (IF/ELIF/ELSE)
----------------------------------------------------------------------
Used to make decisions based on conditions. Code blocks are defined 
by indentation (4 spaces).

Example:
    score = 75
    if score >= 80:
        print("Grade: A")
    elif score >= 50:
        print("Grade: B")
    else:
        print("Grade: F")

----------------------------------------------------------------------
6. LOOPS (FOR & WHILE)
----------------------------------------------------------------------
Loops repeat a block of code multiple times.

- For Loop: Iterates over a sequence (like a list or range).
  Example:
      for i in range(3): # range(3) yields 0, 1, 2
          print(f"Iteration {i}")

- While Loop: Continues running as long as a condition remains True.
  Example:
      count = 0
      while count < 3:
          print(count)
          count += 1

Keywords:
- 'break': Exits the loop entirely immediately.
- 'continue': Skips the rest of the current round and jumps to the next.

----------------------------------------------------------------------
7. DEFINING FUNCTIONS
----------------------------------------------------------------------
Functions are reusable blocks of code wrapped together. Defined 
using the 'def' keyword. They can accept inputs (parameters) and 
send back outputs using the 'return' keyword.

Example:
    def add_numbers(num1, num2):
        result = num1 + num2
        return result

    # Calling the function
    total = add_numbers(5, 10) # total becomes 15

----------------------------------------------------------------------
8. EXCEPTION HANDLING (TRY / EXCEPT)
----------------------------------------------------------------------
Prevents your program from crashing when an error happens.

Example:
    try:
        user_input = int(input("Enter a number: "))
    except ValueError:
        print("❌ That wasn't a valid integer sequence!")
    finally:
        print("This block runs no matter what happens.")

----------------------------------------------------------------------
9. FILE OPERATIONS & WORKING WITH JSON
----------------------------------------------------------------------
Always open files using the 'with' statement. It closes the file 
automatically when done.

- Reading plain text (.txt):
    with open("notes.txt", "r") as file:
        content = file.read()

- Reading structural data (.json):
    import json
    with open("data.json", "r") as file:
        python_dict = json.load(file) # Converts text to a Python dict/list

----------------------------------------------------------------------
10. INTERMEDIATE: LIST COMPREHENSIONS
----------------------------------------------------------------------
A shorthand, elegant way to create new lists out of existing ones.

Standard way:
    squares = []
    for x in range(5):
        squares.append(x**2)

List Comprehension way:
    squares = [x**2 for x in range(5)] # Output: [0, 1, 4, 9, 16]
