======================================================================
                   THE ULTIMATE JAVASCRIPT HANDBOOK

----------------------------------------------------------------------
1. VARIABLES & VARIABLES SCOPES
----------------------------------------------------------------------
Variables hold data values. Modern JavaScript uses three keywords:

- 'let': Declares a block-scoped variable that can be changed.
- 'const': Declares a block-scoped variable that CANNOT be reassigned.
- 'var': The legacy keyword. Function-scoped, prone to scoping bugs.

Rules: Must start with a letter, underscore (_), or dollar sign (\$). 
Cannot start with a number. Uses camelCase conventions by default.

Example:
    const username = "Alice";
    let score = 0;
    score = 10; // Valid!

----------------------------------------------------------------------
2. DATA TYPES & TYPE CHECKING
----------------------------------------------------------------------
JavaScript values belong to one of these fundamental types:

- String: Text wrapped in single, double quotes, or backticks.
- Number: Handles both integers and decimals natively.
- Boolean: True or False (All lowercase!).
- Null: Represents intentional absence of any object value.
- Undefined: Automatically assigned to a variable that has been 
  declared but not yet initialized with a value.
- NaN (Not a Number): Represents an invalid numerical calculation.

Check data types using the 'typeof' operator:
  console.log(typeof 42);       // Output: "number"
  console.log(typeof null);     // Output: "object" (Legacy JS bug)

----------------------------------------------------------------------
3. BUILT-IN DATA STRUCTURES (COLLECTIONS)
----------------------------------------------------------------------
- Arrays: Ordered lists that can hold duplicates and multiple types.
  Syntax: let fruits = ["apple", "banana", 123];
  Add item: fruits.push("orange"); // Adds to the very end

- Objects: Key-value maps for structured properties.
  Syntax: let userProfile = { name: "Alice", score: 95 };
  Access item: userProfile.name or userProfile["name"]

----------------------------------------------------------------------
4. OPERATORS QUICK GUIDE
----------------------------------------------------------------------
- Strict Equality (===): Checks both value AND type without changing 
  them. Always use this over the weak equality (==) operator.
  Example: 5 === "5" evaluates to FALSE.
- Type Coercion: Adding a number and a string concatenates them.
  Example: 5 + "5" evaluates to the string "55".
- Exponentiation (**): Power operator. Example: 2 ** 3 = 8

----------------------------------------------------------------------
5. CONDITIONAL STATEMENTS (IF/ELSE IF/ELSE)
----------------------------------------------------------------------
Conditions must be wrapped inside parentheses (), and execution blocks 
are wrapped inside curly braces {}.

Example:
    let score = 75;
    if (score >= 80) {
        console.log("Grade: A");
    } else if (score >= 50) {
        console.log("Grade: B");
    } else {
        console.log("Grade: F");
    }

----------------------------------------------------------------------
6. LOOPS & TERMINATIONS
----------------------------------------------------------------------
- For Loop: Standard step configuration loop.
  Example:
      for (let i = 0; i < 3; i++) {
          console.log(`Iteration ${i}`);
      }

- While Loop: Repeats as long as a baseline boolean remains true.
  Example:
      let count = 0;
      while (count < 3) {
          console.log(count);
          count++;
      }

----------------------------------------------------------------------
7. FUNCTIONS & ARROW SYNTAX
----------------------------------------------------------------------
Functions package reusable execution strings. They can be written 
with the 'function' keyword or as ES6 'Arrow Functions' (=>).

Standard function:
    function greet(name) {
        return "Hello " + name;
    }

Arrow function shorthand:
    const greet = (name) => `Hello ${name}`;

----------------------------------------------------------------------
8. ASYNCHRONOUS JAVASCRIPT & EVENT LOOP
----------------------------------------------------------------------
JavaScript executes line by line on a single thread but manages 
delays via Promises and the Event Loop.

- Promises: Objects tracking whether a future event succeeds or fails.
- Async/Await: Modern, clean framework to write asynchronous events 
  so they look like regular synchronous code lines.
- SetTimeout: Built-in method to trigger actions after specific intervals.
  Example: setTimeout(() => console.log("Hi"), 2000); // 2 seconds

----------------------------------------------------------------------
9. ERROR HANDLING (TRY...CATCH)
----------------------------------------------------------------------
Catches internal run-time failures safely to secure uptime stability.

Example:
    try {
        let items = JSON.parse("invalid json string");
    } catch (error) {
        console.log("❌ Parsing error intercepted safely!");
    }

----------------------------------------------------------------------
10. INTERMEDIATE: ARRAY METHODS
----------------------------------------------------------------------
Modern JS manipulates arrays elegantly without basic loops:
- .map(): Loops an array, adjusts items, returns a new matching array.
- .filter(): Extracts elements passing a custom criteria check.
- .reduce(): Flattens elements down into a singular accumulated item.
