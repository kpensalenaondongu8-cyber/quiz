======================================================================
                     THE ULTIMATE GO (GOLANG) HANDBOOK                     
======================================================================

----------------------------------------------------------------------
1. ENTRY POINT & PACKAGES
----------------------------------------------------------------------
Go is a compiled, statically typed language developed by Google. Every 
executable Go program must follow these rules:
- Must start with a package declaration (usually 'package main').
- Requires an explicit 'main()' function inside the main package.
- This 'main()' function serves as the single execution entry point.

Example:
    package main
    import "fmt"

    func main() {
        fmt.Println("Hello, World!")
    }

----------------------------------------------------------------------
2. VARIABLES & TYPE INFERENCE
----------------------------------------------------------------------
Go variables are typed. You can declare them explicitly or let Go 
infer the type automatically:

- Explicit Declaration ('var'): Used anywhere, including globally.
  Syntax: var score int = 100

- Short Variable Declaration (':='): Can ONLY be used inside functions.
  It automatically determines the data type.
  Syntax: username := "Alice" // Infers string type

If you declare a variable but do not give it a value, Go assigns a safe 
default called a ZERO VALUE:
- Integers/Floats default to: 0
- Booleans default to: false
- Strings default to: "" (empty string)
- Pointers/Slices/Maps default to: nil

----------------------------------------------------------------------
3. DATA STRUCTURES: ARRAYS VS. SLICES
----------------------------------------------------------------------
- Arrays: Fixed length defined at creation. Size cannot be altered.
  Syntax: var numbers [5]int // An array of exactly 5 integers

- Slices: Built on top of arrays, but dynamically resizable. Slices 
  are used far more often than raw arrays in Go.
  Syntax: scores := []int{90, 85, 95}
  Add item: scores = append(scores, 100) // Appends to the end

- Maps: Unordered key-value collections.
  Syntax: userScores := map[string]int{"Alice": 95}
  Check key presence safely: value, ok := userScores["Bob"] 
  (If 'ok' is false, the key does not exist)

----------------------------------------------------------------------
4. CONSTANTS & POINTERS
----------------------------------------------------------------------
- Constants ('const'): Declares unchangeable, hard-coded values.
  Syntax: const Pi = 3.14159

- Pointers: Stores the physical memory address of another variable.
  Use '&' (ampersand) to get a memory address.
  Use '*' (asterisk) to read or modify the value at that address.
  Example:
      x := 5
      ptr := &x // ptr holds the memory address of x
      fmt.Println(*ptr) // Output: 5

----------------------------------------------------------------------
5. CONDITIONAL STATEMENTS (IF/ELSE)
----------------------------------------------------------------------
In Go, conditions do not use parentheses (), but execution code blocks 
strictly require curly braces {}.

Example:
    if score >= 80 {
        fmt.Println("Grade: A")
    } else if score >= 50 {
        fmt.Println("Grade: B")
    } else {
        fmt.Println("Grade: F")
    }

----------------------------------------------------------------------
6. THE ONLY LOOP: FOR
----------------------------------------------------------------------
Go does not have 'while' or 'do-while' loops. The 'for' keyword handles 
all looping operations in the language.

- Standard counter loop:
    for i := 0; i < 3; i++ {
        fmt.Println(i)
    }

- Simulating a while loop (omit components):
    count := 0
    for count < 3 {
        fmt.Println(count)
        count++
    }

----------------------------------------------------------------------
7. FUNCTIONS & MULTIPLE RETURNS
----------------------------------------------------------------------
Functions can accept multiple parameters and, unlike Python or JS, 
they can natively return multiple distinct values cleanly.

Example:
    func divide(a, b float64) (float64, error) {
        if b == 0 {
            return 0, fmt.Errorf("cannot divide by zero")
        }
        return a / b, nil
    }

----------------------------------------------------------------------
8. THE DEFER KEYWORD
----------------------------------------------------------------------
The 'defer' keyword schedules a function call to run right before 
the surrounding parent function returns. Multiple defers run in 
Last-In, First-Out (LIFO) stack order. Excellent for closing files!

Example:
    func readFile() {
        file := open("data.txt")
        defer file.close() // Will execute last when readFile completes
        
        // read file operations here...
    }

----------------------------------------------------------------------
9. EXPLICIT ERROR HANDLING
----------------------------------------------------------------------
Go does not use traditional 'try/catch' exceptions. Errors are treated 
simply as values. Functions return an error value as their last result, 
which you must check explicitly.

Example:
    result, err := divide(10, 0)
    if err != nil {
        fmt.Println("❌ Error occurred:", err)
        return
    }
    fmt.Println("Result:", result)

----------------------------------------------------------------------
10. CONCURRENCY: GOROUTINES & CHANNELS
----------------------------------------------------------------------
Go is built from the ground up for high performance scaling using:

- Goroutines: Extremely lightweight execution threads. Prefix any 
  standard function call with the 'go' keyword to run it concurrently.
  Syntax: go calculateData()

- Channels: Conduits that allow concurrent goroutines to safely 
  send and receive data among themselves, preventing corruption.
  Syntax: ch := make(chan int)
  Send data: ch <- 42
  Receive data: value := <-ch
